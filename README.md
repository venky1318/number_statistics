# Number Statistics

## Project Overview

Number Statistics is a Python program that analyzes a list of integers. It separates even and odd numbers into two lists and identifies the largest and smallest values.

## Objective

To practise loops, conditional statements, the modulo operator, and basic numerical processing using Python.

## Problem Statement

Processing a list of numbers manually to identify even and odd values and determine the largest and smallest numbers can be repetitive. This project automates these operations using Python.

## Features

- Stores numerical values in a Python list.
- Separates even and odd numbers.
- Finds the largest number using `max()`.
- Finds the smallest number using `min()`.
- Validates the input list.
- Displays results in a structured format.

## Technologies Used

- Python 3
- Visual Studio Code
- GitHub

## Sample Dataset

`[12, 7, 18, 5, 0, -3, 22, 9]`

## Expected Results

| Metric | Result |
|---|---|
| Total numbers | 8 |
| Even numbers | `[12, 18, 0, 22]` |
| Odd numbers | `[7, 5, -3, 9]` |
| Largest number | 22 |
| Smallest number | -3 |

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run `python number_statistics.py`.

On Windows, you can also try `py number_statistics.py`.
